# 알러지 추가접수 자동화 시스템

Flask 기반 웹 애플리케이션으로 병원등록번호를 입력받아 PyAutoGUI를 사용하여 자동화 작업을 수행합니다.

## 설치 방법

1. 필요한 패키지 설치:
```bash
pip install -r requirements.txt
```

## 사용 방법

1. Flask 애플리케이션 실행:
```bash
python app.py
```

2. 웹 브라우저에서 `http://localhost:5000` 접속

3. 두 가지 방법으로 사용 가능:
   - **개별 입력**: 환자명과 병원등록번호(8자리)를 직접 입력하고 제출
   - **엑셀 파일 업로드**: 여러 환자 정보가 담긴 엑셀 파일을 업로드하여 일괄 처리

### 엑셀 파일 형식

엑셀 파일은 다음 형식을 따라야 합니다:

- 첫 번째 행은 헤더입니다 (자동으로 건너뜀)
- **A열**: 환자명
- **B열**: 병원등록번호(8자리)

예시:
| 환자명 | 병원등록번호 |
|--------|-------------|
| 홍길동 | 12345678    |
| 김철수 | 87654321    |

**참고**: 컬럼명이 "환자명", "이름", "등록번호", "번호" 등을 포함하면 자동으로 인식합니다.

## 중요 사항

### 좌표 설정 필요

`app.py` 파일의 `automate_registration()` 함수에서 다음 좌표들을 실제 화면 좌표로 변경해야 합니다:

1. **등록번호 입력창 좌표** (line ~60):
   ```python
   registration_input_x = 500
   registration_input_y = 300
   ```

2. **날짜 좌표 리스트** (line ~80):
   ```python
   date_coords = [
       (x, y, 'YYYY-MM-DD'),  # 실제 날짜 좌표와 날짜 문자열로 변경
       ...
   ]
   ```

3. **Action 버튼 좌표** (line ~100):
   ```python
   action_button_x = 600
   action_button_y = 500
   ```

4. **채혈접수 버튼 좌표** (line ~110):
   ```python
   blood_test_x = 650
   blood_test_y = 550
   ```

### 좌표 확인 방법

1. PyAutoGUI의 `pyautogui.position()` 함수를 사용하여 마우스 위치 확인
2. 또는 `pyautogui.displayMousePosition()` 실행하여 실시간 좌표 확인

### 날짜 좌표 설정

날짜 좌표는 다음 형식으로 설정해야 합니다:
```python
date_coords = [
    (x1, y1, '2026-02-16'),  # 3일 전
    (x2, y2, '2026-02-17'),  # 2일 전
    (x3, y3, '2026-02-18'),  # 1일 전
    (x4, y4, '2026-02-19'),  # 오늘
    (x5, y5, '2026-02-20'),  # 1일 후
    (x6, y6, '2026-02-21'),  # 2일 후
    (x7, y7, '2026-02-22'),  # 3일 후
]
```

## 기능

### 개별 입력
- 환자명과 병원등록번호를 직접 입력하여 한 건씩 처리

### 엑셀 파일 일괄 처리
- 여러 환자 정보를 엑셀 파일로 업로드하여 자동으로 순차 처리
- 처리 결과를 성공/실패 건수로 확인 가능
- 실패한 항목 목록 제공

## 주의사항

- PyAutoGUI는 화면 자동화 도구이므로 실행 중에는 마우스와 키보드를 사용하지 마세요.
- 마우스를 화면 모서리로 이동하면 자동화가 중단됩니다 (FAILSAFE 기능).
- 엑셀 파일 일괄 처리 시 각 작업 사이에 자동으로 대기 시간이 있습니다.
- 실제 환경에서 사용하기 전에 충분히 테스트하세요.
- 업로드된 엑셀 파일은 처리 후 자동으로 삭제됩니다.
